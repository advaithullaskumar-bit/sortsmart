2. CORE TECH STACK & AI LAYER
--------------------------------------------------------------------
• AI Vision Model: Google Gemini 3.7 / 3.6 Multimodal Vision API (gemini-3.7-flash)
• Intelligence Core: Safety-first policy engine (decision-engine.mjs)
• Backend API: Vercel Serverless Function (api/classify.mjs) & Node.js
• Frontend UI: HTML5, CSS3, Vanilla JavaScript (outputs/index.html)

--------------------------------------------------------------------
3. KEY SAFETY FEATURES
--------------------------------------------------------------------
1. Low-Confidence Filtering: Perception confidence below 72% automatically routes items to "Human Review Required" instead of guessing.
2. Safety-First Overrides: Hazardous items (batteries, needles, chemicals) are strictly routed to Hazardous Waste regardless of convenience tags.
3. Real-Time Impact Metric: Compresses 15-minute municipal rule lookups into a 3-second camera scan.
